# Спортика — сайт детской спортивной школы

Статический сайт, собранный по структурной схеме из ТЗ (PDF). Чистый HTML + Tailwind (CDN)
+ ванильный JS. Без сборки — открывается из коробки на любом статическом хостинге.

## Запуск

```bash
cd docs
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Дизайн-система (сгенерирована скиллом ui-ux-pro-max)

- **Стиль:** Claymorphism-lite — мягкие тени, скруглённые формы, дружелюбно, но опрятно.
- **Палитра:** `#1E3A8A` (основной) · `#3B82F6` (вторичный) · `#F97316` (CTA) · `#EFF6FF` (фон).
- **Шрифты:** Baloo 2 (заголовки) / Nunito (текст).
- Токены и компоненты — в `assets/css/styles.css`.

## Страницы и соответствие схеме

| Файл | Раздел схемы | Что внутри |
|------|--------------|------------|
| `index.html` | Главный экран + «Главная» | Оффер, 3 кнопки (Записаться на пробное / Расписание / Войти), для кого, преимущества, как проходит первое посещение, отзывы, FAQ, форма заявки |
| `napravleniya.html` | Направления / услуги | Карточки программ, возраст/уровень, описание результата, тренеры по направлению |
| `raspisanie.html` | Расписание | Фильтр по возрасту/направлению/тренеру, актуальность мест, запись на слот, лист ожидания |
| `trenery.html` | Тренеры | Карточки, опыт, специализация, видео, связь с расписанием |
| `cabinet.html` | Личный кабинет | Вход по телефону, профиль, дети-участники, история заявок/оплат, уведомления |
| `oplata.html` | Оплата | Онлайн-оплата картой, оплата по ссылке, статус платежа, чек |

## Что технически заложено (раздел 4 схемы)

- **Формы и автозаполнение:** `autocomplete`, маска телефона (RU), чекбокс согласия ПДн.
- **Запись:** модальное окно бронирования на всех страницах + плавающая кнопка на мобильном.
- **Расписание:** клиентская фильтрация, счётчик найденных слотов, пустое состояние.
- **Оплата:** mock-эквайринг с состоянием «успешно», номер платежа, чек.
- **SEO:** уникальные `title`/`description`, canonical, Open Graph, JSON-LD, `sitemap.xml`, `robots.txt` (кабинет закрыт от индексации).

## Точки интеграции (раздел 5 — подключает подрядчик)

Формы помечены `data-mock-form` и сейчас имитируют отправку. Для боя:

- **amoCRM** — отправка заявок (имя, телефон, направление, возраст, источник/UTM) в `main.js`,
  обработчик `form[data-mock-form]`.
- **Эквайринг** — реальная инициализация платежа в инлайн-скрипте `oplata.html`.
- **Яндекс.Метрика / Директ** — добавить счётчик и цели на сабмиты форм и нажатия CTA.
- **Расписание** — заменить статичные слоты на подгрузку из CRM/1С (контейнер `[data-schedule]`).

## Доступность и качество

Контраст ≥ 4.5:1, видимый фокус, `label` у всех полей, `aria`-атрибуты,
адаптив 375/768/1024/1440, поддержка `prefers-reduced-motion`, SVG-иконки (без эмодзи).
